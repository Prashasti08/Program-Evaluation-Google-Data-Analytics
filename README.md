# Learning Program Evaluation | Google Data Analytics Certificate

## Project Overview
Conducted an **independent learning program evaluation** of Google's Data Analytics Certificate using **Kirkpatrick's Four-Level Model**, drawing on secondary research and learner experience to identify opportunities for improving training effectiveness.

## Methodology
**Approach:** Kirkpatrick's Four-Level Evaluation Model

- **Learner Experience:** Examined learner reactions and course engagement.
- **Learning Outcomes:** Reviewed available evidence of knowledge and skill development.
- **Program Effectiveness:** Assessed available secondary evidence and identified gaps in measuring learning transfer and longer-term outcomes.
- **Improvement Recommendations:** Developed evidence-informed recommendations for continuous program improvement.

## Tools
Secondary Research | Kirkpatrick's Evaluation Model
